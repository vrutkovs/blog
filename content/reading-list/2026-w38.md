# Software Engineering & Cloud

* [A 40ms Go GC pause caused by swap](https://frn.sh/go-gc/)

  Swap in production was expected to absorb memory spikes for a Go application, but Go's garbage collector metadata — critical for stop-the-world pauses — got evicted to swap instead. GC pause times jumped from microseconds to tens of milliseconds as page faults hit metadata access, and message allocation times rose too. Swap itself isn't the problem; it's how badly it interacts with Go's GC.

  Tags: Go, GC, Swap, Performance, Kernel

* [Busy Door](https://joaquimrocha.com/busy-pixoo/)

  An automated "busy" sign for a home office door, built from a Divoom Pixoo display and a Python script pulling from an iCal calendar. It shows a busy icon with time remaining during meetings, a warning icon beforehand, a random image when free, and dims at night — signaling unavailability to family during WFH meetings.

  Tags: WorkFromHome, Automation, Display, Calendar, Project
