# Software Engineering & Cloud

* [Security doesn’t (always) have to be… so fucking annoying](https://joshua.hu/security-useless-changes-theatre)

  Masking a user’s own email address, blocking password pasting, and rejecting logins by location can frustrate legitimate users without stopping attackers. Security controls need to account for how people actually use a product.

  Tags: Security, Usability, User, Design, Annoyance

* [Home Assistant 2026.11: A lot in store!](https://www.home-assistant.io/blog/2026/11/04/release-202611/)

  Home Assistant 2026.11 adds a built-in Marketplace, exclusions for automation targets, Matter camera support with two-way audio, LoRaWAN integration, and local storage for backups and media.

  Tags: Release, Marketplace, Automation, Integration, Update

* [Progress Report: Linux 7.3](https://asahilinux.org/2026/11/progress-report-7-3/)
