# Software Engineering & Cloud

* [eMudhra Intermediate CA Compromise](https://emudhra.we-have-a-problem.com/)

  Private keys for eight eMudhra intermediate certificate authorities were compromised, creating a risk of website impersonation. Major browser
 vendors have blocked the certificates, but clients may need browser, operating system, or developer-tool updates to reject them.

  Tags: eMudhra, Compromise, Certificate, Security, Revocation

* [php2shell by Calif Research](https://calif.io/php2shell/)

  Two patched PHP memory-safety bugs can lead to remote code execution in mod_php and PHP-FPM deployments. Memory-limit bypasses and out-of-memory handling leave dangling pointers or stale state; affected installations need the October security updates.

  Tags: PHP, Vulnerability, RCE, Memory, Security

* [Mastodon 5.0: A closer look](https://blog.joinmastodon.org/2026/10/5.0-a-closer-look/)

  Mastodon 5.0 redesigns its interface with a pop-out composer, simpler navigation, rebuilt feeds, and new color themes. Community feedback has already changed the composer and content settings, while search and settings remain on the team's list for later work.

  Tags: Mastodon, Redesign, Update, UI, Feature
