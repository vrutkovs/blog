# Artificial Intelligence & Society

* [LLMs: Vigilatism is not the Answer](https://blogs.gnome.org/mortenw/2026/09/27/llms-vigilatism-is-not-the-answer/)

  Adding a "Probabilistically Automated" tag to a Gnumeric bug report became a case study in judging work by provenance instead of quality. This report was requested, useful, and well tested; blanket hostility to LLM-assisted work replaces review with vigilantism.

# Software Engineering & Cloud

* [How Linux readahead works, and the two ways to change it](https://victoriametrics.com/blog/linux-readahead-and-fadvise/)

  Linux prefetches file data into page cache based on observed read patterns, growing batches up to `read_ahead_kb`. `posix_fadvise` can steer this behavior, but its sequential, random, will-need, and don't-need hints carry limits that their names conceal.

  Tags: Linux, Kernel, Readahead, Fadvise, Performance

* [The road to daily-drivable mainline phones](https://nura.eco/blog/2026/09/29/road-to-main-category/)

  Nura defines a "main" category for Linux phones with upstream kernel support, working essentials, and maintainers committed for years. Fairphone 5, Motorola Edge 30, and Radxa Dragon Q6A are first candidates for this ten-year lifecycle target.

  Tags: Nura, Mainline, Device, Linux, Phone
