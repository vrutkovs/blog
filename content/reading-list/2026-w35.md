* [My agent.md to improve LLM-assisted code quality](https://fabiensanglard.net/agent.md/index.html)

  Fabien Sanglard shares his journey using LLMs for coding, detailing initial frustrations with code quality and subsequent improvements through iterative feedback. He introduces `agent.md`, a configuration file injected into LLM prompts to enforce coding style, commit message guidelines, and design principles, significantly enhancing generated code quality. The article also addresses context dilution in LLMs and provides strategies for mitigation.

  Tags: LLM, Agent, Code, Quality, Style

# Software Engineering & Cloud

* [Progress Report: Linux 7.2](https://asahilinux.org/2026/08/progress-report-7-2/)

  The Linux 7.2 progress report for Asahi Linux highlights significant advancements in supporting Apple Silicon. Key achievements include implementing a UEFI Runtime Service-based PSCI conduit for CPU power management, emulating Apple's Secure Page Table Monitor (SPTM) for M4+ devices within the m1n1 hypervisor, and substantial progress on M3 hardware (webcam, microphone, USB/Thunderbolt, display controller). Work is also underway for M4/M5 NVMe and PCIe. Additionally, hardware-accelerated video decoding (AVD) is functional with desktop integration planned, and efforts are progressing towards direct scanout for display efficiency using Apple's Interchange framebuffer format. Ongoing upstreaming of drivers and acknowledgement of new contributors are also noted.

  Tags: Linux, Apple, Power, Security, Video

* [Everything I own, owned](https://schlarp.com/posts/everything-i-own-owned/)

  Turning Claude loose on the firmware of five USB and WiFi peripherals, and finding a command shell in a microphone, a defeatable webcam activity LED, and unauthenticated memory writes over the network.

  Tags: Firmware, Security, Exploit, Peripheral, Agent

* [Eeink Provides EInk, ESP32 Powered Text Adventures](https://hackaday.com/2026/08/27/eeink-provides-eink-esp32-powered-text-adventures/)
